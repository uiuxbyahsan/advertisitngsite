# Billboard Connection - Advertising Site

Outdoor advertising website and campaign brief planner.

## Getting Started

```bash
cd website

# Build HTML pages
npm run build

# Start local preview server (http://localhost:5173)
npm run dev
```

For more details, see [`website/README.md`](website/README.md) and [`website/ASSET-INVENTORY.md`](website/ASSET-INVENTORY.md).
